Problem Description

Utilizing Three.js, we propose a project that simulates the generation of a Voronoi diagram in a
three-dimensional initial cubic volume to act as a pedagogical aid for the process of 3D Voronoi creation.
The user can select the amount of different points inside the region.Each point is then randomly placed.
Once the user starts the program, a set of calculations is done to produce Delaunay tetrahedrons inside the
volume. After these tetrahedralizations are done, the app calculates the circumcenters of each one. This, in
turn, produces the vertexes vertices of Voronoi cells. Each cell divides the interior of the cubic volume to
illustrate the three-dimensional partition. Additionally, we give the user the ability to rotate/move the
camera to some extent.

In order to highlight the important steps of the algorithm, we will have certain points where the
algorithm will pause and highlight an edge/vertex/surface, waiting for the user to press the “next” button.
There may be text alongside this as needed. There will also be a button to run the simulation without any
pausing so that the user can see the entire algorithm run at once.
