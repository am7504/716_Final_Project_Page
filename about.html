Problem Description

Utilizing Three.js, we built a project that simulates the generation of a Voronoi diagram in a three-dimensional initial cubic volume to act as a pedagogical aid for the process of 3D Voronoi creation. The user can select the amount of different points inside the region. Each point is then randomly placed. Once the user starts the program, a set of calculations are done to produce Delaunay tetrahedrons inside the volume. After this tetrahedralization is done, the app calculates the circumcenters of each tetrahedron. This, in turn, produces the vertices of Voronoi cells. Each cell divides the interior of the cubic volume to illustrate the three-dimensional partition. Additionally, we give the user the ability to rotate/move the camera to some extent.

In order to highlight the important steps of the algorithm, we will have certain points where the algorithm will pause and highlight an edge/vertex/surface, waiting for the user to press the “next” button. There may be text alongside this as needed. There will also be a button to run the simulation without Additionally pausing so that the user can see the entire algorithm run at once.

Background Information

A voronoi diagram is a method of partitioning space into cells, where each cell corresponds to a region that is closest to a specific point (called a seed point). Delaunay triangulation is a method of connecting a set of points in space to form a mesh of triangles such that no point is inside the circumcircle of any triangle.

This concept can be extended to three dimensions, where tetrahedrons are formed instead of triangles. Voronoi diagrams and delaunay triangulations (or tetrahedralizations in 3D) are duals, meaning that one can derive one from the other. The vertices of the voronoi diagram correspond to the circumcenters of the tetrahedrons in the delaunay tetrahedralization, and the edges of the voronoi diagram correspond to the faces of the tetrahedrons. This duality allows for a relatively simple process to create the voronoi diagram.

To make this work, We assume that the input points are distributed within a bounded cubic volume. This is because the delaunay tetrahedralization algorithm we are using splits a tetrahedron into smaller tetrahedrons, so the seed points must all be located within the first tetrahedron, which contains teh bounding cube.

Interesting Choices

One interesting choice we made is to use the incremental algorithm for the delaunay tetrahedralization. Despite it not being the most efficient algorithm, this algorithm is relatively simple to implement and understand, making it a good choice for a pedagogical aid. It allows for simple step by step explainations.
